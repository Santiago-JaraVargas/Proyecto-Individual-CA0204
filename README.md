# Proyecto-Individual-CA0204
# Dificultad de los calendarios de la UEFA Champions League 2025/2026

**Autor:** Santiago Jara Vargas  
**Curso:** Herramientas de Análisis de Datos I  
**Universidad de Costa Rica — 2026**

## Descripción

Este proyecto analiza la dificultad de los calendarios de los 36 equipos participantes en la fase de liga de la UEFA Champions League 2025/2026. Se construye un indicador de dificultad utilizando las puntuaciones Elo y la condición de localía, cuyos resultados se comparan con la clasificación final de la competición.

## Estructura del repositorio

- `cod/`: código utilizado para el análisis.
- `data/`: datos utilizados en el proyecto.
- `res/`: informe final en formato PDF.

## Reproducción

Para reproducir el análisis, se debe clonar el repositorio, contar con los datos necesarios, instalar los paquetes de R requeridos y renderizar el archivo `.qmd` mediante Quarto.
